# 水体焦散、泡沫与 SSR 合约

本文补充[水体基础合约](water.md)。新增参数均为可保存／共享的 Resource；动态历史及渲染目标只在内存中，不序列化到场景或资产。

## 物理焦散

- `WaterCausticsSettings` 定义启用、光束网格／接收纹理分辨率、世界接收尺寸、无 SWE 时的明确平底深度、最大光程、遍历预算、强度和过滤半径。`WaterBody3D.sun_path` 是场景节点引用，指定唯一的 DirectionalLight3D，不写入通用资产。
- `WaterCausticsGPU` 借用水体的发布纹理。`surface.gdshaderinc` 共享基础自由面、烘焙模型／旧深度混合、近岸小波坡度及旋转区域采样；不生成独立噪声或焦散动画，不使用进程 TIME。近岸小波按参考项目作周期 Catmull–Rom 坡度重建，仅扰动法线，不改变真实几何或 SWE。
- 发射网格为接收范围的 1.5 倍，并按平面折射方向和中心水深向上游平移。光束足迹换算成 FFT 格数，基础法线差分半径按参考项目限制在 0.02～1 FFT 格，再施加同源近岸小波坡度及自己的足迹渐隐；按该光学法线执行空气到水的 Snell 折射。不是固定半个 SWE 格求法线，也不把画面像素足迹用于光束。
- 有 SWE 时将光线转换到局部网格，在双线性床面片中按前后顺序 DDA 遍历，并解析求两个二次方程根，保留最近有效命中。无效床面不作为平底，四角未完整覆盖的片不接收光束。不将端点同号当作必定无交点；预算耗尽返回 miss，不伪造接收点。
- 无 SWE 时使用资产明确指定的水平接收平面；不冒充任意场景三角网格追踪。首版没有源项目的高度 min/max 树加速，遍历预算按双线性片计数。
- 光束携带入口菲涅耳损失和按真实光程计算的 RGB 消光。启用泡沫时，近岸按密度到光学透明度、远海按覆盖率衰减入射光；这是泡沫覆盖近似，不是单气泡追踪。
- 邻接光束组成三角形，以入射投影面积／三维接收足迹面积计算照度，限制最小足迹。随后按相邻有效面的实际面积加权，将通量重建到共享顶点，线性插值后加法累积到世界空间 RGBA16F 目标；不再将每个三角形整块染为常量色。对完整接收网格，插值积分保持原正则化面通量；裁剪、屏外和缺失接收面仍可能丢失贡献。跨高度断层的接收三角形按共享中心床面判据拒绝，不从无效面借入通量。采样使用五点过滤和接收范围边缘渐隐。
- 光束精度与接收贴图精度独立。资源默认 256 光束格／1024 接收贴图；beach 预设为 512／2048、过滤半径 0.5 texel，64 m 范围对应约 18.75 cm 光束格和 3.125 cm 接收像素。只提高接收贴图不能补回光束欠采样；每轴翻倍约增加四倍对应存储／处理。支持最多 1024 光束格／4096 接收贴图，未承诺最大配置性能。
- 水面在实际背景／折射接收点处检查床面匹配与水下高度，再将照度除以对应平水面参考照度，调制背景后执行观察方向介质积分。Godot 场景颜色已包含各种灯光，因此该合成调制的是匹配接收点的完整背景，不声称从 G-buffer 精确分离并替换单个太阳直射项；照度生成是物理折射光束，最终重照明仍是屏幕空间近似。
- 暂停冻结波面和泡沫，方向／介质／参数变化仍更新焦散。资产网格精度变化只重建焦散资源，不重置水体。释放或重建 WaterGPU 前必须先关闭借用其纹理的焦散实例。
- 不包含入水前几何阴影、完整垂直岩壁、洞穴、多次散射、有限太阳盘／光谱色散或体积焦散；欠采样的折叠可能闪烁，极端设置没有能量收敛／性能保证。

## 水上泡沫

### 状态与时间

- `WaterFoamSettings` 管模拟／生成／寿命／输送／双相位周期和远海雅可比参数；`WaterFoamMaterialSettings` 管 NSH 来源、颜色、尺寸、微法线、粗糙度、覆盖／不透明度尺度、坐标使用及视觉抬高。
- 近岸记录为面泡沫量 `ρ`、两个局部平面泡沫动量 `ρ*v`、可选水面残余 `R`，以及两套世界 XZ 反向材质位移。ρ 是任意单位的量／面积，不是除以水深的浓度，不裁切到 [0,1]。
- 泡沫与水体守恒状态分离，不向水体施加质量或动量。启用时水体 CFL 另外覆盖泡沫的 12 m/s 输运速度上限，可能收紧数值步长，但不新增水体源项。
- 远海单独保存有界覆盖率 F 与位移雅可比 J，不与近岸密度、沙地残留或湿润历史混用。每个实际接受的 tick 更新一次，近岸则跟随每个实际 SWE 子步。水体暂停冻结全部历史和相位；关闭模块冻结 F、近岸历史及材质相位并隐藏外观，J 仍可作为当前 FFT 诊断重算。
- 物理／床面／SWE 重建会清空近岸历史；若原始 FFT 波谱参数和共同时间仍有效，在 GPU 复制独立远海覆盖历史。显式水体 Reset、原始波谱更换或场景重入清空相应历史。N/R 模式切换按当前 FFT 相位重新初始化近岸，不迁移两种不同输送模型的动态状态。

### 生成、输送和寿命

- 默认单浓度用共享正向面的 Rusanov 迎风权重守恒输送量和两个泡沫动量；二阶水体下可选择受限 MUSCL 泡沫空间重构。预测／校正使用对应不可变水体与泡沫阶段，RK2 两阶段平均，源项和衰减仅在完成子步后积分一次。
- 干湿／边界／地形阻断处退回一阶，干格不得外排泡沫；露出水面的高床面和缺失床面关闭跨面通量，淹没后允许输运。闭域无源无衰减时总量守恒，汇聚增密无需额外乘增益。
- FFT 开边界不输入外部泡沫，只允许出流，并沿与 SWE 一致的松弛带衰减。水深不超过 3 mm 时清除水上泡沫与位移，不生成湿沙／沙地沉积。
- 背景生成使用真实子步水位上升、波速和压缩／bore 信号；前沿生成沿当前流向在四个距离采样点比较有效湿贡献者速度，只将接近／追赶强度转成源项。静止没有流向，零上升且零阈值采用严格大于，避免静水自己产泡。没有引入独立近岸造波器。
- 生成率、源开关、衰减和拖曳实时生效。关闭 emission 不清空历史。冻结系数下量的生成／指数衰减与拖曳／新生速度联合解析积分，零衰减、瞬时拖曳和无拖曳有独立分支，防止除零。
- 远海使用水平位移雅可比 J，在每秒源率 `generation*clamp(threshold-J,0,1)` 下解析更新 `F'=source*(1-F)-decay*F`，F 保持 [0,1]。默认阈值 0.65，不在平坦 J=1 海面产泡；显式设阈值大于 1 会允许平坦面生成。
- 可选 N/R 实验保留源项目的非守恒半拉格朗日回溯与局部面积压缩响应，两种水面泡沫共同输送；解析积分 N 衰减、N→R 转化和 R 独立衰减，处理相同／接近寿命的稳定极限。R 不是沙地。它不承诺严格守恒，且不沿用默认泡沫惯性／拖曳模型。

### 材质坐标与显示

- 反向位移跟随泡沫输运速度回溯，只使用湿贡献者并归一化坐标权重，不跨过阻断的对角路径；不使用干格的零坐标拉扯湿域。
- 两套米制位移错开半周期，只在不可见时重置。相位按 GPU 实际接受时间增量积分；编辑周期保留已有相位，不重算 `绝对时间/新周期`。周期 0 为持续输运。先独立阈值／着色，再混合预乘色及不透明度，不能先混合孔隙纹理。
- 携带三种 NSH 派生纹理：Shorewaves、Crest Foam、Crest Foam2。RG 是编码法线，B 是 Soft，A 是 Height；作为线性数据导入，保留四通道，禁用透明边缘修复／预乘和自动有损 3D 压缩，生成线性 mip。来源及 MIT 通知见 addon SOURCE 和 textures/foam/ 下许可。
- NSH 使用粗／细两层采样，以密度控制孔隙覆盖、指数响应控制光学不透明度。微法线按输运坐标相对世界坐标的雅可比变换，覆盖水面高光后以哑光近似显示；不把光学不透明度写回模拟密度。
- 可调视觉高度只抬高渲染网格及泡沫基础法线，不修改真实水位、水深、动量、光束使用的物理水面或泡沫生成。密度、最终不透明度、输运坐标网格可单独调试。
- N/R 显示采用 N 的 NSH 外观盖在 R 的窄带孔隙外观之上；未迁移源项目所有实验性脊线源、独立 N 材质／阈值面板和浓度幂调制开关，不宣称所有旧 UI 参数一一对应。

## SSR：验证原生后迁移

- `tests/water_ssr_test.gd` 在同一真实 Forward+ 场景中以不透明金属镜面作正对照。固定红色物体在原生镜面上能被 Environment.ssr_enabled 明显反射；当前屏幕取样／自定义介质和高光水面开启同一原生开关没有水面反射变化。因此没有将“启用了环境 SSR”冒充水面已兼容。
- `WaterSSRSettings` 配置水面自有 SSR 的启用、最大米制距离、像素遍历预算、世界命中容差、法线偏移及强度。只更新材质，不重建物理／泡沫／焦散历史；不替用户修改 WorldEnvironment 的全局 SSR。
- `ssr.gdshaderinc` 迁移原 screen_trace 的投影线段、齐次 W／深度面裁剪、由不透明场景深度重建世界点及世界射线命中判据，适配 Godot 反向 Z 和 UV。使用当前最终混合波面法线，兼容透视及正交相机。
- 当前采用有界逐像素 DDA，没有源渲染器的独立屏幕 min/max 深度金字塔加速；同一数字的遍历预算不等同于源项目的树节点预算。步数低可能漏掉远处有效命中，高步数会增加像素成本，不承诺性能等价。
- 命中必须位于局部物理波面以上，排除水底作为水上倒影。采样当前不透明场景颜色，按屏幕边缘／距离渐隐后先混合环境反射，再应用水面菲涅耳；不是把反射颜色直接加到最终颜色。
- 零强度、超距、预算耗尽、遮挡或屏幕外没有可见样本时回退已有 HDR 经纬反射图／反射颜色。只反射当前相机可见的不透明几何，不恢复透明对象、屏幕外或被前景遮挡的表面。
- 保留 SSR only／hits 调试视图；不生成 CPU 读回，不使用上一帧命中作为本帧有效性的替代。没有时域重投影、粗糙反射卷积或多重反射。

## 诊断与验收

- `WaterGPU.snapshot()`：`foam` 每格 8 float 为 `[ρ,px,pz,R,Dax,Daz,Dbx,Dbz]`，动量在区域局部坐标，D 为世界米制反向位移；`offshore_foam` 每格为 `[F,J,近岸材质相位,0]`。它们只用于显式排查／导出，普通帧不回读。
- `WaterCausticsGPU.snapshot()`：返回实际光束 origin／hit／transmission 与接收 Image，同样可能等待 GPU。普通焦散更新不回读。
- 计时 UI 的 Sim GPU 是 FFT／SWE／泡沫／发布的时间，不含独立焦散追踪／光栅、水面 SSR 或整帧绘制成本。
- `water_caustics_test.gd`：平底 Snell／菲涅耳／RGB 解析照度、斜向太阳和发射上游偏移、真实斜坡烘焙高度场、接收纹理世界方向及资源独立性；用低光束／高接收精度的斜床解析梯度检验连续照度。另以独立 Fourier 模式输入实际光束，由命中点逆 Snell 恢复法线，核对参考小波格点响应／增益、跨格一阶导数、周期边界、足迹渐隐、开关／无 FFT／无 SWE 隔离，以及深水模型内部不混回 FFT 几何。
- `water_foam_test.gd`：远海独立解析 ODE、活源停发后保留、量超过 1、两阶闭域输送的独立积分衰减、缺失格隔离、30／60 Hz、N/R 及材质周期连续性、远海历史跨近岸资源重建。
- `water_effects_scene_test.gd`：真实焦散背景重照明、实际泡沫可见性、NSH／颜色／抬高编辑保留状态，以及三种实际导入纹理四通道和 mip 数据契约。
- `water_ssr_test.gd`：原生正对照与水面兼容性、迁移后的真实反射及菲涅耳合成、正交相机、强度／距离／预算边界、miss 环境回退、透明目标排除和物理实例不重建。
