# GPU 水体合约

## 节点与参数资产

- `WaterBody3D` 的世界 Y 是平均水位。直接子节点可包含一个启用的 `FFTDeformer3D` 和一个启用的 `SWEDeformer3D`；重复启用同类形变器报配置警告并停止显示，不隐式决定叠加顺序。可使用静态、仅 FFT、仅 SWE 或 FFT→SWE 模式。
- 水体和 SWE 区域支持平移、世界 Y 旋转；自身及祖先不得缩放、镜像、倾斜。源几何可以有自己的缩放和旋转。
- 九类可保存为 `.tres` 的 Resource：基础 `WaterFFTSettings`、`WaterSWESettings`、`WaterBakeSettings`、`WaterSurfaceSettings`、`WaterMaterialSettings`，以及 `WaterCausticsSettings`、`WaterFoamSettings`、`WaterFoamMaterialSettings`、`WaterSSRSettings`。节点默认各自创建参数资源；显式共享资产时编辑影响所有引用者，独立调整使用 Make Unique。动态状态始终逐水体独立，不属于共享资源。
- Source Root 的 NodePath、节点变换、形变器启用、编辑器模拟开关与暂停属于场景实例；不将场景节点引用写入可跨场景共享的参数资产。
- 参数资产校验有限值、尺寸和支持范围。FFT 分辨率是 8～512 的二次幂，SWE 每轴 8～512 格；显示网格精度独立。无效配置不分配对应 GPU 场、不显示伪造动态水面。

## 高度场与编辑器区域

- `SWEDeformer3D` 原点是烘焙盒底中心，`WaterBakeSettings.size` 决定宽、高、深；Y 采样范围 `[0,size.y]`，XZ 网格使用单元中心。区域支持原生平移／Y 旋转和宽高深 Gizmo，尺寸编辑使用编辑器撤销／重做，修改的是烘焙资产，故共享资产的其他引用者同步变化。
- 烘焙收集 Source Root 下可见、非蒙皮的静态 MeshInstance3D，以及根 CSGShape3D 的最终布尔网格。排除 `water_bake_ignore`（可配置）及自动生成水面。不生成可保存的 CSG 代理节点，不改变场景几何、碰撞或角色。
- 使用 Godot 顺时针正面，在局部 Y 区间内保留每格最高的向上表面；逐采样裁切跨界斜面，不夹平到盒顶。不采用雾烘焙的坡度限制。源网格镜像时修正绕序。竖直退化投影不产生床面。
- 输出为单层 RG32F 内存 Image：局部床高和 0/1 有效标志。无采样、有效干地和有效湿地是不同状态；高度零可以是有效床面。默认不补底；显式启用 fallback 才以盒内指定高度填补缺失格。
- 所有格均无效且未启用 fallback 时烘焙失败；旧内存 Image 可保留用于排查，但签名立即失效，不继续模拟或显示。内部缺失床面在 SWE 中是封闭周界，不沿用雾的开放排出语义。
- 进入场景树时清空上次缓存，等待两帧使 CSG 就绪，再自动烘焙。区域变换、尺寸、分辨率、Source Root 或补底配置变化后旧结果失效，需要显式烘焙。源几何编辑不自动扫描；执行 Bake 更新。
- 退出／重新进入场景树必须重新采样。场景只保存参数和来源，不保存高度场、Image、ImageTexture、Texture2DRD、生成网格或模拟历史；烘焙本身不要求保存场景。

## FFT

- CPU 用确定性 Phillips 波谱产生复数 h₀ 和世界 XZ 波向量，清除 DC 与 Nyquist 行列。Godot RNG 与源 Rust SplitMix64 不同，同资产可复现，但不保证相同种子跨语言逐位一致。
- GPU 使用深水频率 `sqrt(9.81*|k|)` 演化，并用两轴 radix-2 IFFT，每轴最后一级除以 N。六通道分别为显示波高、两个水平位移，以及 SWE 输入波高、两个深度积分水平动量。
- 三个输入通道使用同一波长低通；默认拒绝 ≤12 m、≥24 m 完全通过，中间 smoothstep 过渡，零过渡为硬截止。显示通道不受输入过滤影响。
- 基础几何及输入周期采样采用未形变世界 XZ，FFT 格点坐标 `(world/length+0.5)*N`，周期双线性插值；显示纹理采样补偿纹素中心偏移。近岸小波坡度另用周期 Catmull–Rom 重建，不改这条几何／输入采样链路。
- 正常路径不回读全场。显示波高增益只应用一次；水平挤浪是显示位移，不是水流速度或动量。

## SWE 与 FFT 输入

- 每格守恒状态为水深 h（m）、两个局部坐标深度积分动量 hu/hv（m²/s）。床面上传时转换成相对平均水位的米制高度。
- 一阶采用静水重建 Rusanov + Euler；二阶采用受限自由面／速度／床面 MUSCL、配套床面源项与两阶段 SSP-RK2。干湿及无效邻域退回一阶。两者使用相同共享面供给格排出量限制，保证水深非负；末尾裁零只作舍入保护，显著负深度和 NaN/Inf 增加 fault 计数。
- 重力默认 9.81 m/s²，可配置；Manning 摩擦默认 0.03，局部速度保护上限 12 m/s。不继承雾的约化重力、重力阈值或背景风动量。
- 未选中的矩形区域边界反射；选中的 FFT 边界使用零梯度外态及内部松弛带。无 FFT 时所有外边界封闭。内部缺失床面始终反射。闭域质量使用 `sum(h)*dx*dz`，不以渲染透明度衡量；FFT 开边界和松弛源可增减总水量。
- 输入同时包含过滤后水位和由线性连续方程得到的匹配动量，不使用水平挤浪位移或其时间导数。世界动量按区域 Y 旋转变换到局部坐标。显示波高增益与 SWE input gain 的乘积对水位和动量共同应用一次。
- 极端输入采用共同安全缩放，保持水位／动量比例；干格清除动量，浅格有速度保护，因此安全限幅情况下不承诺原始波幅。
- 参数／床面重建从当前共同模拟时刻的过滤 FFT 全域建立水深和动量，显式水体 Reset 则从 t=0 开始；正常推进只在配置的松弛带读取输入。两端 FFT 水位和动量均保留，每个 SWE 子步按阶段时间插值；初始化时两个端点都必须具有已定义的数据。
- 耦合仅为 FFT→SWE。SWE 不反向影响波谱；短波过滤和松弛带不能把非色散 SWE 变成有限水深色散模型。

## 时间、生命周期与诊断

- 主线程累积 60 Hz 固定 tick，一批最多追赶四个 tick、另保留四个 tick 的欠账；超额请求时间计入 `dropped_cpu_time`。
- GPU 每子步归约实际状态及重构面的最大传播速率，以 CFL=0.2 选实际 dt，且不超过松弛源的稳定步长。CPU 只估计提交子步预算，不能替代 GPU CFL。资产 max_substeps 限制每 tick 预算；预算不足时缩短实际推进并记录 `dropped_gpu_time`，不强行采用不稳定步长。
- GPU 接受的模拟时间是共同真值。含 SWE 时，先计算请求 tick 终点 FFT 供子步插值，再在实际接受时刻重算显示 FFT；这比单纯每 tick 一次 FFT 更贵，但预算不足也不会使显示相位提前。没有 SWE 时只需终点 FFT。
- 暂停同时冻结物理状态、FFT 和模拟时间。`editor_simulate` 默认关闭，编辑器仍能看初始化静态水面；编辑器模拟开关会重建初态。动态编辑器状态不保存，运行时从初态开始。
- 波谱、物理、输入过滤／增益／边界和重新烘焙会重建 GPU 状态，不迁移 SWE 历史；若旧 GPU 实例仍有效，则在 GPU 内复制共同模拟时钟，使用当前 FFT 相位初始化，不回读 CPU。显式 Reset、编辑器模拟开关、重新进入场景从 t=0 开始。区域／水位编辑导致烘焙失效时旧实例立即关闭；之后重烘焙已无运行时钟可继承，也从 t=0 开始。
- 材质、显示网格密度／大小、SWE 显示 surface_mode、normal_strength 及旧模式 blend_depth 只更新显示／光学，不重置状态。Choppiness 更新水平显示位移及独立远海泡沫的雅可比输入，但不重建 SWE／清空历史。共享资产变化通过 Resource.changed 到达每个引用节点。
- 全局 RenderingDevice 的资源创建、计算、复制、释放都在渲染线程。基础／泡沫输出为稳定的 RGBA32F Texture2DRD，焦散另用 RGBA16F，水面直接采样；正常帧不调用 submit/sync，不逐帧上传或读取全场。
- `WaterGPU.snapshot()` 是显式阻塞式诊断边界，返回状态、波场、床面、实际时间、故障和丢时；不供逐帧 UI 使用。GPU 计时取异步真实 timestamp，和 CPU 提交时间分开；无样本显示 −1，不声称固定性能预算。
- 退出、重置、初始化失败及快速修改配置必须释放旧 GPU 资源；异步旧初始化结果不得覆盖新实例。

## 渲染与限制

- 水面在一个显示网格上混合 FFT 与 SWE 的绝对自由面，而不是相加；FFT 水平挤浪随其显示权重退出。默认 Heightfield 模式采用参考项目模型分支：烘焙区域内部由 SWE 接管，不按深度重新引入粗 FFT 几何；所有边沿两格宽的覆盖渐隐与选中 FFT 边界的松弛带负责过渡。Depth Blend 模式显式保留旧沙坡深度混合，只有该模式使用 Blend Depth。两种模式仅改显示／光学，不修改守恒状态。
- 基础法线来自混合曲面差分。近岸按参考 surface.wgsl 取 FFT 一格／四格中心差分坡度之差，在格点上以周期 Catmull–Rom 双三次重建，再应用一次米制间距和波高增益。normal_strength 默认 1，范围 0～3；水深 0.02～0.25 m 渐入，足迹 0.5～2 FFT 格渐出。水面与抬高泡沫使用同一小波坡度、各自基础法线；GGX、菲涅耳、SSR／折射使用一致的最终法线。小波只扰动渲染／光学法线，不抬高几何、不向 SWE 回写或叠加额外水位。
- 湿自由面插值忽略干格的高床面，避免露出岩石附近的假水丘；水深和覆盖标志仍独立用于干格剔除，默认薄于 8 mm 不显示。
- 材质使用 Forward+ 场景颜色与反向 Z 深度重建水中光程，以线性 RGB 计算 Beer-Lambert 透射和常数源解析积分（含消光为零的极限）。使用按折射率计算的菲涅耳和介电 GGX 直射高光。
- 环境反射使用资产提供的经纬 HDR 图；缺失时回退显式反射颜色，不自动声称读取当前天空或 SSR。快速折射做一次局部接收高度估计、屏幕偏移限幅与深度拒绝，失效回退直线光程，不能恢复屏幕外／被遮挡背景。
- 已接入折射光束焦散、近／远海泡沫、可选 N/R 和水面自定义 SSR；原生 SSR 的真实兼容性对照、算法与参数边界见[水体效果合约](water-effects.md)。仍是上方观察、单层高度场和不透明背景水面，没有湿沙历史、浪花粒子、浮力、角色交互、跨区域通量、重叠透明水层、相机入水、分层物理折射或完整天光积分。不保证与 Rust 原图逐像素相同；Godot 管理原生灯光、天空、色调映射和雾。

## 验证入口

- `tests/water_bake_test.gd`：CPU 采样、旋转／跨界／陡坡／镜像、CSG 更新、缺失和补底、实际场景保存／重载／重入与资产保存／共享／独立编辑。
- `tests/water_gpu_test.gd`：真实 GPU 六通道直接 DFT 对照、两阶静水平衡、传播和闭域质量、干湿推进／孔洞周界、旋转输入和一次增益、30／60 Hz 提交、零输入增益、CFL 预算不足及最终显示相位。
- `tests/water_scene_test.gd`：真实展示场景、CSG→GPU→材质链路、岩石遮挡、深浅水、材质实效、外观编辑不重置、暂停／重烘焙／重置／重入、旧 GPU 所有者可回收，以及两米水柱的独立解析光学对照。

- `tests/water_caustics_test.gd`、`water_foam_test.gd`、`water_effects_scene_test.gd`、`water_ssr_test.gd` 的光学、历史、实际像素与原生 SSR 正对照职责见[效果合约](water-effects.md#诊断与验收)。
