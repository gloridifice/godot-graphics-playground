# 局部高度雾 SWE 合约

本文描述 `simulation_method=SWE`（默认）的求解行为。另有可切换的 [Stable Fluids 后端](heightfield-stable-fluid.md)，不继承 SWE 的重力、动量守恒或汇聚堆积语义。现有 `swe_enabled`／`swe_editor_enabled`／`swe_paused`、重置及诊断入口为兼容保留，操作当前选中后端；切换重置到相同资源初态，不迁移动态状态。

## 状态与方程

每个雾盒独立维护二维单层浅水状态：厚度 `h`（m）、相对背景风速的局部 X/Z 单位宽度扰动动量 `h*u`、`h*v`（m²/s）。零风速时与原动量定义相同；实际输送速度为背景风速加扰动速度。承载高度来自该盒烘焙的 RG 高度图；有效标志为零的格子不参与。使用可配置约化重力（默认 1.2 m/s²）近似低层重气体，不求解三维空气、浮力混合或温度。

每盒可配置 `SWE Gravity Threshold`（`swe_gravity_threshold`，0～8 m，默认 0）：按离承载面的厚度计算，不是世界 Y 高度。令阈值为 `t`，有效重力厚度 `a=max(h-t,0)`，压力为 `g*a²/2`，重力波速为 `sqrt(g*a)`。`t=0` 恢复原有重力行为。阈值实时生效、不重置状态；只影响重力压力、静水压力修正及对应波速／数值扩散，不关闭冲量、惯性输送或阻尼。无风且不超阈值、无动量的薄雾保持静止，但阈值不是厚度硬下限，也不保证受扰后保留同样厚度。

`shaders/swe.glsl` 默认使用分片常量的一阶有限体积 Rusanov 型通量，可通过 `SWE Second Order` 启用带限制器的空间重建；质量数值扩散中的重力波部分使用有效重力厚度差，惯性部分仍使用总厚度差，避免低于阈值的静止雾被数值扩散摊平。采用静水重建和两侧压力修正维持水平自由面的静水平衡。无承载格的交界面和矩形盒外边界统一为开放边界，不作为反射墙，不区分孔洞是否与盒外连通。风吹入有效格时补雾，流出时移除；无风／横风时仍允许压力或玩家扰动向外排出。干格可被通量润湿；没有向外部雾盒交换通量，即使两个盒体在世界空间重叠。

有行走采样的提交批次先执行一次独立 GPU 动量交换阶段，再进行以下子步。该阶段只写动量、不改厚度；后续 CFL 归约读取已施力状态，不在通量模板中重复计算人体源项。

每个子步：
1. 重置最大波速诊断。
2. 对包含本步起跳冲量的状态做全局 GPU 波速归约；一阶 CFL 系数 0.45，二阶空间重建模式为 0.3，考虑 X/Z 两个方向及重建界面波速。
3. 计算所有右／上界面通量。
4. 用供给格可排出水量限制共享界面通量，再更新厚度与扰动动量；施加指数扰动动量阻尼并写厚度输出纹理。
5. 按实际子步长度积分世界空间风偏移，并写 1×1 RGBA32F 相位纹理供显示读取；与通量更新隔离，避免同一子步读写相位竞态。

排出量限制保持非负和跨格质量一致；最终 `max(h,0)` 仅作浮点误差保护。干格清除动量，不删除厚度。NaN/Inf 恢复会增加 fault 计数，不能把该路径视为正常质量守恒。浓度、边缘渐出和显示噪声属于着色，不是模拟质量；验证质量使用 `sum(h) * dx * dz`；无边界通量的域总质量守恒；开放域的质量变化来自边界补充／排出，包括流向无承载格后直接消失的雾。

## 可选二阶空间重建

- 节点 `SWE Second Order`（`swe_second_order`，默认 false）同时适用于编辑器和运行时；关闭保留原一阶路径。切换会重建物理初态并清零动量／输送偏移，即使当前暂停也生效；保留固定的预览密度相位，便于同图案对照，不重烘焙地形。
- 开启后在每条轴的左右邻格上，对自由面 `bed+h` 和相对风的速度使用 MC（monotonized-central）斜率限制器，重建两侧界面状态，再执行原静水重建和共享 Rusanov 通量。重建厚度限制在本格及面对邻格的平均厚度范围内，压力修正使用同一侧重建厚度，维持静水平衡并防止新的厚度极值。
- 外边界、内部无效格、干格及其相邻重建模板退化为原一阶；上风补入及下风排出规则不变。供给格排出量限制仍负责非负和共享通量守恒。
- 时间推进仍是原显式一阶子步，没有加入 RK2／Hancock 时间预测；这是可选的二阶空间重建，不宣称整个求解器达到时空二阶精度。较密模板访问与更保守的 CFL 会增加 GPU 成本；主要减小风输送的数值扩散，不取消重力产生的真实摊平，也不保证长期不模糊。

## 时间与扰动

- 主线程积累 60 Hz 固定模拟 tick；基于初态最大厚度、网格尺寸和最大并发冲量估算子步数（最多 64）。GPU 独立限制实际子步长度。
- 极端状态超过估算时，GPU 缩短子步并增加 `cfl_limited_steps`，物理推进时间会小于请求时间；不偷偷扩大时间步。`simulated_time` 记录实际推进时间。
- 每次更新最多追赶四个 tick，再保留四个 tick 的积欠；超额时间计入 `dropped_time`，避免卡顿后无限提交。默认森林稳定采样段未新增丢时或 CFL 限速；启动卡顿可能触发追赶截断，累计值保留用于诊断。
- `disturb_mist(world_feet, radial_strength=1)` 将脚底转换为盒体局部坐标；强度限定在 [−1, 1]，负值向内汇聚、正值向外扩散，零值不排队，非有限值拒绝。只增加径向速度对应的动量，不直接改变厚度。半径默认 2.5 m，速度增量默认 1.8 m/s，再乘事件强度；影响随半径与承载面到脚底的垂直距离衰减，垂距 1.5 m 外为零。省略强度保持原来的向外冲量。
- `fog_playground` 的真实接地起跳发送 −0.8 强度，落地发送 +1，各一次；出生初次接地与空中二段跳不发送地面扰动，向下速度不超过 1 m/s 的微小接地不施加落地冲量。输入释放不阻止重力或真实落地扰动。
- 每盒在两个 tick 之间最多排队四个事件，满时丢弃最旧事件；事件的局部脚底 XYZ 与有符号强度 W 一起送入 GPU；每批事件只作用于第一个子步一次。暂停时不接受冲量。后续厚度由通量输送、重力和阻尼决定，没有固定恢复计时器。

## 接地行走推动与尾流

- `HeightfieldFogBox.push_mist(from_feet, to_feet, duration)` 接受世界坐标脚底轨迹与物理采样时长（秒），转换为盒体局部坐标。主场景控制器在真实 `move_and_slide()` 前后采样，仅连续接地且未起跳时发送；使用实际位移，不使用输入、模型朝向或期望速度。站立、完全顶墙、空中移动不持续施力，斜坡移动保留两端脚底高度。
- 速度低于 0.05 m/s 的接触修正忽略；非有限输入、时长不在 `(0, 0.1]` 秒或水平速度超过 20 m/s 的采样拒绝，避免将传送当作步行。暂停、未初始化或关闭 SWE 时不接收，不在恢复时回放暂停期间的移动。重置随求解器一起清空队列。
- 每盒 **Interaction / Movement** 的 `Movement Radius` 为有效近地体宽尺度（默认 0.65 m），`Movement Coupling` 为动量耦合率（默认 7 s⁻¹，0 关闭），`Movement Wake` 为平面尾流强度（默认 0.65，0 关闭尾流但保留前推及侧向分流）。这些参数实时生效、不重建初态，与跳跃半径／速度独立。
- GPU 按扫掠段的最近点计算前方顺行推动、两侧向外分流，以及身后顺行拖曳与一对反向平面环流。按 `1-exp(-coupling*weight*duration)` 与绝对流速耦合，再存回相对背景风的动量；不是每帧叠加固定速度。长扫掠段按驻留比例缩短每格暴露时间。承载面到轨迹的高度差在 0.15～0.8 m 渐出，0.8 m 外不施力，无效／干格不造雾。
- 行走独立于四个径向事件槽；每盒最多积累 16 个物理轨迹采样，超限丢弃最旧。每次有固定 tick 可推进时消费一次，多个追赶 tick 和 CFL 子步不重复回放。正常路径只上传最多 784 字节轨迹缓冲，没有场纹理上传或 GPU 回读。
- 源项不直接修改厚度、不以时间恢复空洞。前方／两侧堆积、路径变薄及停止后的衰减来自 SWE 输送、压力与动量阻尼；源项本身不增减雾量，开放边界仍可生成／移除雾量。森林示例未连接该接口，保留原有起跳交互。
- 这是人体尾流的二维物理启发近似，不是三维空气动力学：不模拟腿部步态、热羽流、竖向下洗或真实湍流脱落频率；速度场系数为效果参数，不是论文标定值。调研依据与适用范围见[实验场指南](../guides/playground.md#行走气流调研与二维近似)。

## 风输送与开放边界

- Natural Mist 开启且 Wind Speed 非零时，复用资源的世界 Wind Direction／Speed，按盒体 Y 旋转转换成局部背景速度；在通量和 CFL 中使用背景风加扰动速度。厚度、空隙、堆积与玩家扰动一起被搬运，不再只是密度纹理漂移。重力阈值不限制风输送，阻尼只衰减相对风的扰动速度，不把背景风减慢。
- 无承载格的交界面与矩形盒边界使用同一生成／消失规则，无需连通性分类，也不把无效格解释成无限高的实体。无效格本身始终保持零厚度；补入发生在相邻有效格，排出直接移除厚度和对应动量。内部封闭孔洞也适用；真实有效地形的高差仍参与静水重建。
- 上风开放面按风速注入新厚度，新雾的扰动动量为零。用同一资源的无缝噪波及高度公式，在世界坐标减累计风偏移后连续采样；沿风向拉伸、频率、种子、层数、偏移、基准高度、水平雾顶、初始厚度上限均生效。边界承载高度用最近有效边缘格外延；不在无效格补雾。上限同时限制初态和新雾，不裁切已有模拟堆积。Horizontal Top 模式下，入口厚度为带噪波雾顶减边缘承载高度再裁零；高于雾顶的入口可持续补入零厚度，并在下游形成缺雾带，不绕过高度公式强行造雾。
- 下风开放面按当前实际向外速度带走厚度与扰动动量，不反弹，不允许从下风侧反向补雾。斜风可在 X/Z 两轴同时开启入口和出口，实际周界可包含多段。无风／横风的开放面以同承载高度的干外态求通量，只允许向外排出，不反向造雾；压力阈值与玩家／惯性动量仍正常生效。底层地形障碍不是新的流体绕障碍空气模型。
- Wind Speed=0 时停止风补入与背景输送，不重置已有厚度；无承载处与盒边仍可接受压力／扰动驱动的向外排出，不恢复反射墙。修改风速不重置，累计噪波偏移连续，不因变速跳相位。关闭 Natural Mist 也关闭风输送，但属于初态形状变化，会重建状态；风向修改同样会重建。
- 各盒独立生成和排出，不跨盒传递；总雾量不要求恒定。Coverage、浓度和密度细节仍只参与显示，不作为边界质量源。
- SWE 暂停时厚度、补充／排出和密度风偏移一起冻结。未启用 SWE 的编辑器／静态模式保留只有密度纹理漂移的预览，不模拟边界。

## GPU 与显示

- `swe_solver.gd` 使用 Godot 全局 RenderingDevice；资源创建、计算提交、释放都通过渲染线程回调。每盒拥有独立状态双缓冲、地形、两组界面通量、诊断缓冲、R32F 厚度纹理、噪波采样纹理、80 字节风配置缓冲、784 字节行走采样缓冲与 1×1 风偏移纹理。
- FogVolume 通过 Texture2DRD 直接采样输出，不逐帧回读 CPU，也不逐帧上传厚度纹理。正常更新不调用 `submit/sync`；Godot 管理提交及渲染顺序。
- 静态显示与 SWE 初态使用同一份资源噪波厚度，不存在独立的程序化雾顶覆盖。Noise Amplitude／Frequency／Octaves／Seed／Offset 都参与初态，Max Thickness 限制初态及上风补入的新雾；模拟可继续堆积。软密度剖面、风向密度纹理和边缘渐出仍可使用；密度与边界采样共享 GPU 积分的输送偏移；密度另保留开启 SWE 前的预览偏移作为固定显示起点，避免纹理切换时零演化也变图案。异步初始化期间冻结该起点，暂停同时冻结静态预览与 GPU 输送。开关 SWE 重置输送偏移而不替换预览起点；显式重置、形状变化及重新进入场景才同时清零预览起点。不使用进程启动时间，不叠加第二层持续漂移。见 [薄雾生成合约](heightfield-mist.md)。
- 模拟不强行裁切厚度到渲染范围；`SWE Render Height` 默认 8 m，为动态堆积预留显示保护范围，极端堆积超出时应增大该值并检查 `maximum_height`。
- `SWE Enabled` 仅控制运行时，`SWE Editor Enabled`（`swe_editor_enabled`，默认 false）独立控制编辑器。编辑器开关的开启与关闭均重建资源初态、清零动量及累计风偏移；开启后使用同一 GPU 求解器推进，关闭后释放求解器并回到静态初态，不影响运行时开关。预览动态状态不保存，进入运行时仍从初态启动。`SWE Paused` 同时适用于编辑器和运行时，暂停保留当前状态；开关编辑器模拟不会清除暂停标志，暂停下开启会保留新建初态而不推进。运行时开关 SWE、重置、重烘焙或形状参数（含自然模式的风向／拉伸）变化会重建状态。浓度、覆盖率、顶部软化和密度细节只调显示；风速实时改变输送及边界，不重置模拟。共享初始化资产不保存动态状态。GPU 初始化失败明确报错，回退静态显示，不伪造跳跃扰动。
- 旧的渲染密度清空／扩散环已移除。未启用 SWE 的盒体不响应汇聚或扩散冲量。

## 计时与验证

GPU 耗时来自 RenderingDevice 的异步 timestamp，报告最近完成且有时间戳采样的提交批次，可能包含多个固定 tick；不是 CPU 提交时间，也不是整帧时间。每盒在同一已完成时间戳帧内最多记录一组查询，避免只推进模拟、不绘制时耗尽查询池；不为计时强制绘制或同步 GPU。D3D12 驱动将查询计数换算为纳秒，除以 1e6 得毫秒（该版本 XML 接口说明的微秒与驱动实现不一致）。无可用时间戳时返回 −1，不阻塞等待。CPU 提交耗时单列。

`swe_snapshot()` 是显式诊断回读，可能等待 GPU，只供验证／排查；性能采集阶段不调用。`tools/profile_forest_swe.gd` 固定相机、禁用 VSync 与 FPS 上限，依次测暂停／运行／每秒起跳，并在计时结束后读取诊断。

测试职责：
- `swe_test.gd`：一阶／二阶模式均检查 GPU 带实体高边的静水平衡（含阈值跨界）、重力阈值下薄雾静止／超阈值输送／零阈值恢复／薄层冲量、干湿推进、实体高地阻挡、非负、质量、向内汇聚／向外输送、跨高度隔离、强冲量和实际模拟时钟；另用独立的正弦单元平均值平移解析解比较两种模式的 L1 误差及有界性。另覆盖带无承载留白的平台在两种阶数／四个轴向风向下的均匀通流、停止补入后排空、恢复补入后充填、无效格保持空、封闭孔洞在零风下接受压力／冲量排出，以及风从孔洞吹入时仅在正确一侧补雾。行走的主验证也由该测试负责：两种空间阶数与 X/Z 两方向的前推／两侧分流／尾流、真实厚度重分布、跨楼层隔离、停步后动量衰减、质量／时钟／fault，以及相同物理轨迹在 30／60 Hz 提交时的施力一致性。
- `tests/fog_playground_jump_test.gd`：从配置的主场景加载后在测试内将风速设为零，并提高目标盒重力阈值，隔离风补入和静止层的边缘排出；真实第三方角色接地起跳和落地分别造成 GPU 向内／向外动量、汇聚增厚与局部交互质量守恒，并验证默认自由鼠标和 F／Esc／失焦控制生命周期；同一真实主场景另检查 WASD 接地移动送达 GPU 动量、局部交互质量守恒以及暂停期间移动不会在恢复后回放。
- `natural_mist_test.gd`：噪波频率影响实际静态／暂停 SWE 初态画面、非零风下开关 SWE 的零步推进画面一致性及真实零模拟时钟、SWE 厚度进入 FogVolume、旋转盒世界坐标冲量、暂停时外观编辑保留状态、切换空间重建阶数会重置真实扰动，以及 GPU 资源重建；另检查旋转盒运行中缩小承载面后重烘焙，新的无承载周界可生成／排出雾且不堆积，原始高度图保持有效标志。
- `tests/forest_walk_test.gd`：实际玩家空格起跳确实产生 GPU 动量。
