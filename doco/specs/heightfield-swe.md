# 局部高度雾 SWE 合约

## 状态与方程

每个雾盒独立维护二维单层浅水状态：厚度 `h`（m）、局部 X/Z 单位宽度动量 `h*u`、`h*v`（m²/s）。承载高度来自该盒烘焙的 RG 高度图；有效标志为零的格子不参与。使用可配置约化重力（默认 1.2 m/s²）近似低层重气体，不求解三维空气、浮力混合或温度。

`shaders/swe.glsl` 为一阶有限体积 Rusanov 通量，采用静水重建和两侧压力修正维持水平自由面的静水平衡。盒外与无效格为反射边界。干格可被通量润湿；没有向外部雾盒交换通量，即使两个盒体在世界空间重叠。

每个子步：
1. 重置最大波速诊断。
2. 对包含本步起跳冲量的状态做全局 GPU 波速归约；CFL 系数 0.45，考虑 X/Z 两个方向。
3. 计算所有右／上界面通量。
4. 用供给格可排出水量限制共享界面通量，再更新厚度与动量；施加指数动量阻尼并写厚度输出纹理。

排出量限制保持非负和跨格质量一致；最终 `max(h,0)` 仅作浮点误差保护。干格清除动量，不删除厚度。NaN/Inf 恢复会增加 fault 计数，不能把该路径视为正常质量守恒。浓度、边缘渐出和显示噪声属于着色，不是模拟质量；验证质量使用 `sum(h) * dx * dz`。

## 时间与扰动

- 主线程积累 60 Hz 固定模拟 tick；基于初态最大厚度、网格尺寸和最大并发冲量估算子步数（最多 64）。GPU 独立限制实际子步长度。
- 极端状态超过估算时，GPU 缩短子步并增加 `cfl_limited_steps`，物理推进时间会小于请求时间；不偷偷扩大时间步。`simulated_time` 记录实际推进时间。
- 每次更新最多追赶四个 tick，再保留四个 tick 的积欠；超额时间计入 `dropped_time`，避免卡顿后无限提交。默认森林稳定采样段未新增丢时或 CFL 限速；启动卡顿可能触发追赶截断，累计值保留用于诊断。
- `disturb_mist(world_feet)` 将脚底转换为盒体局部坐标。起跳只增加径向速度对应的动量，不直接改变厚度。半径默认 2.5 m，速度增量默认 1.8 m/s，影响随半径与承载面到脚底的垂直距离衰减，垂距 1.5 m 外为零。
- 每盒在两个 tick 之间最多排队四个事件，满时丢弃最旧事件；每批事件只作用于第一个子步一次。暂停时不接受冲量。后续厚度由通量输送、重力和阻尼决定，没有固定恢复计时器。

## GPU 与显示

- `swe_solver.gd` 使用 Godot 全局 RenderingDevice；资源创建、计算提交、释放都通过渲染线程回调。每盒拥有独立状态双缓冲、地形、两组界面通量、诊断缓冲及 R32F 厚度纹理。
- FogVolume 通过 Texture2DRD 直接采样输出，不逐帧回读 CPU，也不逐帧上传厚度纹理。正常更新不调用 `submit/sync`；Godot 管理提交及渲染顺序。
- SWE 开启时实际厚度替代自然模式的程序化雾顶；软密度剖面、风向密度纹理和边缘渐出仍可使用。Top Variation/Scale 不再决定物理厚度，Wind Speed 不对动量施力。
- 模拟不强行裁切厚度到渲染范围；`SWE Render Height` 默认 8 m，为动态堆积预留显示保护范围，极端堆积超出时应增大该值并检查 `maximum_height`。
- 编辑器只显示静态初态。运行时开关 SWE、重置、重烘焙或基础初态参数变化会重建状态；暂停保留状态。共享初始化资产不保存动态状态。GPU 初始化失败明确报错，回退静态显示，不伪造跳跃扰动。
- 旧的渲染密度清空／扩散环已移除。未启用 SWE 的盒体不响应起跳。

## 计时与验证

GPU 耗时来自 RenderingDevice 的异步 timestamp，报告最近完成的提交批次，可能包含多个固定 tick；不是 CPU 提交时间，也不是整帧时间。D3D12 驱动将查询计数换算为纳秒，除以 1e6 得毫秒（该版本 XML 接口说明的微秒与驱动实现不一致）。无可用时间戳时返回 −1，不阻塞等待。CPU 提交耗时单列。

`swe_snapshot()` 是显式诊断回读，可能等待 GPU，只供验证／排查；性能采集阶段不调用。`tools/profile_forest_swe.gd` 固定相机、禁用 VSync 与 FPS 上限，依次测暂停／运行／每秒起跳，并在计时结束后读取诊断。

测试职责：
- `swe_test.gd`：GPU 静水平衡、干湿推进、无效格墙、非负、质量、动量冲量、跨高度隔离、强冲量和实际模拟时钟。
- `natural_mist_test.gd`：SWE 厚度实际进入 FogVolume、旋转盒世界坐标冲量、暂停及 GPU 资源重建。
- `tests/forest_walk_test.gd`：实际玩家空格起跳确实产生 GPU 动量。

仅验证了 Windows / Godot 4.7.2 / Forward+ / D3D12 / RTX 3070；未验证其他驱动或硬件。第一阶通量存在数值扩散；没有跨盒耦合、三维涡旋、树干／倒木动态阻挡或持续风力输送。
