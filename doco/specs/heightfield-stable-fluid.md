# 局部高度雾 Stable Fluids 合约（第一版）

## 选择与共享生命周期

`HeightfieldFogBox.simulation_method` 可选 `SWE`（默认，旧场景不变）和 `STABLE_FLUIDS`。两种模式复用烘焙高度图、`HeightfieldFogInitialization.create_thickness()`、FogVolume、外观和玩家事件入口。现有 `swe_enabled`、`swe_editor_enabled`、`swe_paused`、`reset_swe()`、`swe_metrics()`、`swe_snapshot()` 名称为保存场景和调用方兼容而保留，操作当前选中的后端，不代表此时一定运行 SWE。`SWE Render Height` 同样为两者预留渲染范围。

切换后端、开关相应环境的模拟、重新烘焙或初态形状变化会释放旧资源，并用同一资源重建厚度、清零扰动速度与输送位移，并将高度增益置为中性值 `1`。不迁移动态状态、不重烘焙已有有效地形。切换保留固定的预览密度起点；显式重置和形状变化清零该起点。暂停保留当前状态，拒绝新冲量／行走轨迹，初始化期间不推进显示风偏移。编辑器和运行时使用相同 GPU 路径；动态状态不序列化。初始化失败明确报错，显示静态初态。

主场景运行时 **F2** 切换所有雾盒并重置，左下角显示当前后端；默认仍为 SWE。启动参数 `-- --stable-fluids` 可直接预览 Stable Fluids，不修改场景资产。Inspector 可按盒独立选择；F2 以 GroundMist 的选择为基准统一切换。

## 状态与数值方法

`stable_fluid_solver.gd` / `shaders/stable_fluid.glsl` 实现二维、近似不可压的空气速度场，以及独立的近地径向交互分量。局部 X/Z 速度存于 MAC 交错面，每个槽为四 float：投影空气 X/Z 与径向交互 X/Z；均以扰动速度保存，初态为零。实际采样输送速度为背景风＋投影空气＋径向交互。径向分量近似起跳卷吸／落地下洗的水平投影，不声称总速度严格二维无散，也不模拟真实竖向空气。有效承载格即空气求解域，不因厚度为零而关闭空气速度。承载高度用于显示和交互高差隔离，不产生 SWE 压力、重力、静水重建或高地阻挡。

每个 60 Hz 固定 tick：

1. 用中点回溯和双线性插值输送扰动速度，叠加当前背景风作为轨迹速度。
2. 一次性跳跃／落地事件注入径向分量，真实行走轨迹通过空气速度目标交换作用；对两种扰动施加指数阻尼。
3. 只计算空气分量的散度，压力清零，以固定 Jacobi 次数求解 Poisson 方程。
4. 从空气面速度减去压力梯度，近似满足二维无散条件；径向分量保留，不投影为零。
5. 用合成速度和中点回溯输送反向材质位移、来源元数据与高度增益 `G`；使 `G` 向 `1` 指数恢复，再消费本 tick 的一次性高度交互。按回溯坐标从不可变初态 `h₀` 或入口资源公式重建基础厚度，乘 `G` 后写稳定的厚度及位移输出纹理。上一 tick 的最终厚度不参与新高度的插值。
6. 单独积分世界风位移，供连续入口生成使用。

`stable_pressure_iterations` 范围 8～128，默认 48；实时生效，不重置。`stable_drag` 范围 0～4 s⁻¹，默认 0.45；同时衰减空气和径向扰动速度，不衰减背景风或厚度。SWE Gravity／Gravity Threshold／Second Order／Drag 不影响本后端；在 Stable Fluids 中切换 SWE Second Order 不重置状态。

高度采用**不可变初始化高度 `h₀` + 半拉格朗日反向映射**。初始反向位移为零，每 tick 递推坐标场 `A_next(x)=A_previous(trace_back(x))`，然后重建 `h_base(x)=h₀(A(x))`，最终 `h(x)=h_base(x)×G(x)`；实现以世界反向位移保存映射，不每 tick 恢复原位置，也不递推插值厚度。`h₀` 是 configure 接收的实际厚度图，包括自定义厚度，不用程序化噪波替换它。初态源采样以有效格归一化双线性模板，越出原承载域时不能钳到盒边或穿孔洞采另一片初态。

**基础高度**仍是被动标量，不通过水平汇聚堆积或重力自行摊平；没有高度增益交互时，均匀初态与匹配入口保持均匀。单次 `h₀` 采样仍有有限网格过滤，但不将过滤后的高度反复作为输入，因此匀速风不会持续磨损噪波。坐标场本身仍逐 tick 插值，会在复杂剪切／旋涡下累积轨迹和欠采样误差，浮点精度、有限压力迭代及来源混合也有限制；不是无限时长无损方法，不严格守恒总雾量。尚未加入 MacCormack／BFECC、显式黏性、涡量补偿或自适应步长。

`disturb_mist()` 的负强度向内搬运、正强度向外搬运：在近地径向面速度中施加一次增量，随后由合成流场输送并受 `Stable Drag` 衰减，不再把该梯度场送入不可压投影而立即消除。水平响应只改变后续采样轨迹，不改变 `h₀`、不乘面积压缩因子；非均匀噪波可被聚拢／推开。事件同时作用于下述独立高度增益，所以均匀层也能被临时挑高／压低。源项局部、响应可随流动传播，不给全场基础厚度加扩散／恢复或质量归一化。速度衰减不复位材质坐标；风或后续真实流动可以搬走／替换已有扰动。

行走沿用前推、分流和成对平面环流的速度目标，投影后主要保留绕流／尾流，并按当前合成速度耦合；不会重复注入跳跃事件。高度隔离、队列上限、暂停丢弃、一次消费和传送拒绝规则沿用 SWE 交互入口；Stable Fluids 在有承载但零厚度的空气格也允许施力。

## 临时高度增益

高度增益 `G` 直接编码于 `[0,2]`，中性值为 `1`，最终厚度只做 `h=h_base×G`。`G=2` 为两倍基础厚度，`G=0` 为零厚度；零基础厚度始终保持零，不凭空造雾。不再用初始化 `Max Thickness` 裁切增益后的输出，它只约束基础厚度。该响应是可恢复的视觉高度近似，不守恒总雾量、不反馈空气压力或速度。

`G` 复用每格 `MaterialState.source.z`，不新增场纹理、缓冲尺寸或计算 pass，也不参与初态／入口权重归一化。每 tick 先按同一裁剪轨迹输送，再按模拟时间恢复：`G=1+(G_advected-1)×2^(-dt/T_half)`。仅临时增益接受重复插值，基础噪波仍从不可变来源重建。恢复只把乘数带回 `1`，不会复位 `A` 或恢复原位置的图案。

按队列顺序消费一次性事件，使用与径向速度相同的平滑半径／高差权重 `W`：`G=mix(G,G_target,abs(strength)×W)`。负强度取起跳目标、正强度取落地目标。满强度中心落地可覆盖尚未消退的升高，不采用无限叠加；结果限制于 `[0,2]`。目标为 `1` 时不注入该类新增益，已有增益照常恢复。高度响应独立于 `Jump Speed`，即使径向速度为零仍有效；行走不注入高度增益。

Inspector 参数实时生效，不重置现态：

| 参数 | 范围／默认 | 含义 |
| --- | --- | --- |
| Stable Takeoff Height Gain | `1～2`／`1.75` | 满强度起跳的中心乘数目标；`1` 禁用新增抬高 |
| Stable Landing Height Gain | `0～1`／`0.25` | 满强度落地的中心乘数目标；`1` 禁用新增压低 |
| Stable Height Gain Half Life | `0.01～32 s`／`0.8 s` | 偏离 `1` 的幅度减半所需模拟时间；独立于 Stable Drag |

初始化、重置、切换后端时 `G=1`；暂停同时冻结输送和恢复，拒绝新事件。无效格与外部新流入空气均为中性 `1`，回溯不能跨孔洞携入增益；流出不反弹。新流入空气仍可在当前有效格受本 tick 的真实事件影响。

## 开放周界与输送

矩形盒边与内部无承载孔洞均开放；无效格不保存雾。压力在域外取零，不使用封闭反射墙，不做外部空域连通性分类。背景风从资源按盒体 Y 旋转转换到局部；均匀风不产生散度，不受扰动阻尼影响。

材质回溯沿线逐格检查，遇到第一个无效格或盒边停止，不能只判断终点而跳过孔洞。背景风指向域内时，为新材质记录交点时间的世界风位移和入口承载高度；之后每 tick 在其回溯世界坐标读取同一资源的噪波／高度公式，不把第一次生成的高度继续插值，也不误采盒内 `h₀`。入口参考承载高度随材质输送，不按下游地形或后来改变的入口重算。风速归零保留已有入口材质，反向风只改变之后新进入的材质。

每格保存初态权重、入口权重和入口加权承载高度；剩余权重表示零厚度外部空气。它们随坐标场双线性输送，来源交界允许有限宽度混合。若回溯原点不在 `h₀` 有效域，剔除残余初态权重，并对入口／空域剩余权重归一化，避免混入伪零厚度形成接缝；全空来源不生成雾。无背景风或非入口面的外部空气没有入口权重，即使压力／扰动造成局部吸入也不凭空造雾。插值模板接触域外时同样按入口规则取值。流出没有反弹，也不在盒间交换状态。

每条材质轨迹最多检查 128 个格面；极端步长耗尽预算时停留于已遍历的有效格并增加 `trace_limited`，不跨过未检查区域。常规速度没有 CFL 限步，但大位移仍可能损失轨迹精度；该预算不是任意参数的精度保证。固定 tick 每次最多追赶四次，最多再保留四 tick 积欠，超出部分计入 `dropped_time`。

## 显示与 GPU

使用全局 RenderingDevice，创建、提交、释放均在渲染线程。不可变 R32F 初态高度缓冲、材质／来源双缓冲、面速度双缓冲、压力双缓冲、散度、地形、配置、事件和诊断在 GPU 维护。材质每格仍为 32 字节，包含最终厚度、世界反向位移、初态权重、入口权重、加权承载高度及高度增益；最终厚度只作输出／诊断，不反馈输送。R32F 厚度经 Texture2DRD 直接送入原 FogVolume，正常帧不回读 CPU、不上传场纹理，不自行调用 submit/sync。Stable Fluids 的渲染高度余量至少覆盖初态最大厚度的两倍加过滤余量，同时保留现有 `SWE Render Height` 保护，避免增益被初态包围盒截断。

另输出 RG32F 世界空间反向材质位移：初始为零，随同一局部流场输送，用于 Coverage 和密度细节。Fog shader 在 Stable Fluids 模式读取局部位移，**不再额外叠加全局 GPU 风位移**；静态预览起点仍只加一次。由此，均匀厚度中的旋涡也能移动可见细节。材质位移本身有插值误差和长期拉伸，没有无损或无限时长保证；不定期清零或暗中恢复初态。

`swe_metrics()` 仍报告异步 GPU timestamp、CPU 提交耗时及丢时，不能将压力迭代次数或 CPU 耗时当 GPU 性能保证。显式 `swe_snapshot()` 在本模式返回：

- `scalar`：每格四 float，依次为增益后的最终厚度、世界 X/Z 反向材质位移、初态来源权重；不是 SWE 动量。内部 GPU 每格 32 字节由显式快照整理为该诊断布局。
- `height_gain`：每格一个 float，直接编码的 `[0,2]` 乘数，中性值为 `1`。
- `velocity`：每格两个 float，面速度平均得到的局部 X/Z 合成扰动速度（空气＋径向），不含背景风。
- `radial_velocity`：每格两个 float，单独的局部 X/Z 径向交互速度，供区分近地交互与空气投影。
- `simulated_time`、`last_dt`、`maximum_height`、累计 `faults`／`trace_limited`。
- `divergence_before`／`divergence_after`：最后 tick **空气分量**投影前后最大绝对散度，不代表包含径向交互的总速度散度。

诊断允许阻塞 GPU，仅供显式验证。快照 schema 与 SWE 不同，调用方应根据选中的后端解释。

## 验证与限制

`stable_fluid_test.gd` 为本后端的真实 GPU 数值验证入口：零风不规则厚度静止、投影降低散度、行走尾流输送／高度隔离、向内／向外径向交互存续、仿射初态的独立 `h₀(A)` 查值、禁用高度增益时均匀层不增厚／变薄、未影响远区保形及速度耗散后不自动复位、均匀内域厚度不被造出起伏但材质发生输送、两种盒旋转下 1／6 秒细尺度正弦平移解析对照、四向开放入口、初态／入口接缝均匀性、跨坡入口承载高度保持、反向风来源隔离、8 秒入口噪波解析对照、有孔洞及大位移的逐格回溯；高度增益另验证中性初始化、跨楼层隔离、两倍／零厚度端点、四 tick 追赶只消费一次、正负半衰期、远区保形、受影响干格不生雾、与基础参考同步输送及入口／孔洞中性。另从真实主场景验证 F2 双向切换使用相同初态、非中性增益暂停冻结和重置回 `1`；真实控制器测试同时检查起跳升高与落地压低。

```powershell
& G:\Tools\Godot_mono_v4.7.2\godot_console.exe --path . --script res://addons/heightfield_fog/stable_fluid_test.gd --max-fps 120
# 真实主场景：同一控制器输入／接地事件，Stable Fluids 中检查径向速度与回溯坐标。

& G:\Tools\Godot_mono_v4.7.2\godot.exe --path . -- --stable-fluids
```

当前数值验证通过 Godot 4.7.2 / Forward+ / D3D12 / RTX 3070；同机原 SWE 和自然雾 GPU 回归通过。没有其他驱动验证或性能预算保证。二维单层空气不模拟真实三维浮力、下洗或地形绕流；径向交互是二维近似，只有空气分量被投影近似无散。基础高度沿轨迹保持来源值，独立增益允许临时增厚／减薄；不追求水平面积改变或高度交互时的总雾量守恒；长时间复杂流动仍有映射误差与拉伸。该模式与 SWE 是不同的视觉／动力学选择，不承诺互相等价或无缝迁移。
