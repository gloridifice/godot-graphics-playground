# Sponza View 3：用相同射线预算比较三种暗部消闪算法

## Purpose
完整网格修正了粗拱顶造成的自遮挡，但固定相机下，间接光仍在帧间变化。上轮 RTX 3070 / 720p 的静帧实验中，stride 6 的历史保留率从 0.94 调到 0.98，暗区平均相邻帧亮度差从 0.0526 降到 0.0188（显示值 0–255），SRC 均约 0.62 ms。单看静态画面无法区分降噪和迟滞。当前保存的场景已使用 0.99，不能只把新算法与较弱的 0.94 比。

## Scope and acceptance
在独立的项目副本上分别运行：A 按方向桶自适应探针历史，B 按世界探针计数的低差异方向采样，C 在乘底色前对间接光做带重投影的方差引导滤波。三者不叠加，与相同灯、几何、stride、相机和反弹数的原算法对照。固定 0.98 是单变量基线；再单列未改算法的 0.99，代表用户现场。硬件 RT、完整不透明几何；不改正式 addon 默认行为，不保存测试场景，不改灯、曝光或项目驱动。

交付可复跑的代码和报告。每组给出静止暗部噪声、平均亮度、相机横移边缘误差、移灯响应；另行记录 720p/1080p 预热后的 GPU 中位数、P95、样本数和额外显存。没有达到推荐门槛的算法也保留实测结果。不将实验自动作为默认实现。第一轮之后，按用户要求追加 A+C 叠加实验：在同一 0.995 输入下加入无算法、仅 A、仅 C 三个对照，另存画质、动态响应与 GPU 数据。

## Result
三组已完成独立 GPU 与动态画面测量，见[实测报告与复跑命令](../../../guides/sponza-temporal-stability.md)。相对当前固定 0.99，A 将暗部平均帧差降低 31%，移灯同为 22 帧；B 没有实用的静帧收益；C 更稳但慢 15 帧、1080p SRC 增加 0.654 ms。补充对照固定 0.995 降低 43%，也是 22 帧，优先考虑开放可选参数而非合入更复杂的原型。后续[组合实验](../../../guides/sponza-temporal-combo995.md)显示，相比固定 0.995，A+C 的静帧差降低 95%，但移灯由 22 帧延至 42 帧，1080p SRC 多 0.678 ms；仅 A 配 0.995 则降低 27%，移灯为 23 帧。两轮均未修改正式 addon、场景设置或默认值。
