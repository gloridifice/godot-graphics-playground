# swe-fog-playground

## Purpose

建立可第三人称行走的雾效实验场，落实已确认的“离线场景高度场 + XZ 二维低重力 SWE + 独立雾浓度 + Godot 原生体积雾”方案。先用带网格图案的平面地面、胶囊玩家和第三人称相机建立尺度与观察基准，再接入模拟与渲染。

创建时项目只有 Godot 4.7 Forward+ 配置及默认图标，没有主场景、玩家、相机插件或模拟实现。本变更是待实现方案，不代表功能已经存在；本次请求仅创建变更，不授权执行、完成或归档。

## Scope and acceptance

### 交付范围与顺序

1. **基础场景**：可直接运行的主场景，64 × 64 米黄绿色草地底色平面，1 米间距的程序化网格图案，静态碰撞和基础照明。地面位于 Y=0，XZ 为水平面。
2. **第三人称玩家**：`CharacterBody3D` 搭配可见胶囊体和匹配的胶囊碰撞；WASD 相机相对移动，鼠标环绕观察，Esc 释放鼠标，单击游戏视口重新捕获。使用真实角色重力与地面碰撞，不受雾的有效重力影响。
3. **相机**：优先采用 Phantom Camera 的 Third Person Follow，通过独立相机适配器隔离插件。执行时锁定验证过的稳定版本并保留许可证；若 Godot 4.7 兼容验证失败，可退回原生 SpringArm3D + Camera3D，保持相同操作和防穿透行为，并记录原因。
4. **离线高度场**：编辑器工具从显式选择的静态几何生成浮点高度、有效区域和阻挡信息；保存坐标、分辨率、格式版本及来源校验。即使首场景为平面，也走真实烘焙与加载路径，而非运行时直接假定高度为零。
5. **二维雾模拟**：运行时初始化 XZ SWE 网格，维护雾层厚度、水平动量和独立雾含量；支持弱有效重力、弱风、缓慢消散、稳定子步、边界及非负保护。根据地形高度与层厚确定雾的实际空间位置。
6. **体积渲染**：由二维场驱动 FogVolume 自定义 fog shader，复用 Godot 原生体积光照与积分；模拟与材质之间不做逐帧 CPU 回读。先完成无噪声密度映射，再添加可关闭的低频细节。默认呈明显白色浓雾，初始层厚约 0.25 米，仅到角色脚踝。
7. **诊断与交付说明**：提供厚度、雾含量、速度和雾顶高度调试视图；支持暂停/重置模拟，暂停不妨碍玩家与相机。记录参数单位、运行和烘焙方法、验证结果与未验证限制。参数 UI 可调初始化噪波振幅、频率、层数、种子和允许负值的高度 offset；厚度裁切到 0。数字可直接左右拖拽、Shift 精调或双击输入，数字变化实时重置雾场，无需额外应用；开关不触发重置。提供约化重力开关，关闭后保留风与输送。

### 可观察验收

- 启动进入网格地面场景，胶囊玩家可以在平面上第三人称移动；斜向移动不加速，转动相机后移动方向随相机水平朝向变化。
- 玩家稳定站立、不穿地、不走出实验地面；相机俯仰受限、不翻转，低角度观察不穿地，也不被玩家自身碰撞体顶住。
- 离线烘焙的平面高度与网格坐标正确；改变已选几何后能识别高度场过期，不把未命中数据默认为零高度。运行时不逐帧射线扫描地面。
- 雾层底部为场景高度，顶部为场景高度加厚度；厚度和浓度可以独立调节，不能用一张透明水面代替体积雾。
- 默认参数表现为缓慢、微风驱动的贴地雾，而非明显水波；雾风作用于实际输送，不仅移动材质噪声。
- 无风静水平衡、封闭区域雾量守恒、弱风响应、半衰期、非负状态和帧率独立性通过行为验证；正常场景不依赖不断截断状态掩盖数值问题。
- 在雾中移动及转动相机时，地面与玩家正常遮挡雾；记录薄层采样和时间重投影的实际限制。性能报告区分模拟和体积渲染，未测量时不得宣称达到固定毫秒预算。

### 非目标

- 三维气象/热力学、凝结与蒸发微物理、垂直翻卷烟柱、多层高度场、桥上桥下独立雾层。
- 玩家拨开雾或向雾施力、动态障碍物、复杂地图、美术角色和动画、跳跃/冲刺、手柄与移动端适配。
- FFT 海浪、泡沫、浪花、水面光学，以及把参考仓库整体接入 Godot。
- 自研屏幕空间 Ray March、时间重投影或另一套体积渲染器；原生方案不足时另行评估。

### 预期契约变化

项目将首次拥有可运行主场景、角色与相机操作约定、高度场资产格式及失效规则、二维雾状态/边界/时间推进约定、体积密度映射与 GPU 资源生命周期约定。交付后再将已实现且验证过的契约同步到当前架构与规范；创建阶段不把未来设计写成当前功能。
