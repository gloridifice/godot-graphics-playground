# 雾场离线高度场目标规范

## Scope and current contracts

这是本变更的目标。当前没有高度场格式或烘焙工具；参考仓库的 `.sweh` 文件不是本项目必须兼容的资产格式。首个正式资产来自实验场平面，数值验证另用小型斜坡、台阶和薄墙夹具。

## Requirements

- 烘焙为编辑器中的显式操作；运行时加载已保存资源，不自动重烘焙，也不逐帧查询场景高度。
- 烘焙输入包括静态几何、世界空间 XZ 区域、X/Z 分辨率、选择规则；单位为米，支持矩形区域和不相等的 X/Z 格距。
- 通过明确的 `fog_floor` 和 `fog_obstacle` 分组选择承载地面和阻挡几何；玩家、相机、装饰及未选择对象不参与。
- 每格保留浮点高度与有效标记，另存 X/Z 网格面的通行标记。无命中为无效格，绝不隐式使用 0 米作为地面。有效格以外不初始化雾，也不允许穿越无效格输送。
- 单层高度场对选定地面取最高覆盖表面；重叠的多层承载面应给出不支持/重叠诊断，不声称能够保留桥下空间。薄墙阻挡采用保守的格面覆盖判断，不能仅依赖格点中心射线命中。
- 首版 `fog_obstacle` 是覆盖其投影的不可穿越障碍，不处理从障碍上方越过的雾；可越过的地形起伏应由承载地面高度表达。
- 资产必须包含格式版本、世界坐标原点/范围、分辨率/格距、高度数组、有效数组、格面通行数组、来源标识及校验摘要。高度不量化到普通 8 位图，也不经 sRGB 转换。
- 保存前校验尺寸、数组长度、有限数和坐标范围；先生成完整资源，再安全替换旧资产，失败不损坏已有文件。
- 加载时校验格式、尺寸与来源；静态几何或变换变化后应提示资产过期并停止雾初始化。运行时的一次性来源检查不得变为重新烘焙或每帧几何扫描。
- 模拟与渲染必须采用相同的世界空间映射和单元中心约定；边界不能依赖采样器重复寻址把对侧高度绕回。

## Boundaries, errors and compatibility

- 非静态几何、动画形变、桥上桥下多层、悬垂结构不是本版能力。
- 默认烘焙分辨率与模拟分辨率一致；修改区域或分辨率需要显式重烘焙和重置，不隐式插值已有动态状态。
- 不支持的网格拓扑、空选择、无有效覆盖、损坏/过期资产都返回可读错误；已有可用场景和旧资产保持不变。

## Acceptance scenarios

### T1 平面与坐标

对 Y=0 的实验场平面烘焙，所有覆盖格高度为 0（浮点容差内），64 米范围与中心采样一致。平移/抬高夹具后，得到对应世界坐标，不遗留本地坐标偏移。

### T2 地形与薄障碍

解析斜坡和台阶的高度与预期一致；跨越网格面但不覆盖单元中心的薄墙仍阻断输送，且斜坡本身不被误判为整列障碍。

### T3 无效与损坏数据

留空部分承载几何后对应格为无效；破坏长度、版本或写入非有限高度时加载失败，不能初始化出地面以下或全零高度的假雾场。

### T4 来源与持久化

保存并重新加载得到相同数据；移动被选几何后旧资产报告过期。移动玩家或相机不使高度场过期。模拟运行期间没有逐帧射线烘焙。

## Current-document impact

交付后记录高度场资产格式、选择规则、失效和重新烘焙流程，并同步当前架构中的编辑器工具到运行时资源边界。
