# 第三人称雾效实验场目标规范

## Scope and current contracts

这是本变更的目标，不是当前已实现契约。当前项目只有 `project.godot` 配置，无主场景和操作规范。首场景使用程序化网格平面和胶囊角色，不引入外部场景美术。

## Requirements

- 单位为米；世界 Y 向上，地面覆盖 X/Z 各 [-32, 32]，高度为 0。地面使用黄绿色草地底色以衬托白雾；网格细线间距 1 米、主线间距 5 米，通过材质抗锯齿绘制，不为每根网格线创建几何。
- 地面有稳定的静态碰撞；四周设置边界碰撞防止走出地面。默认玩家出生于中央的无穿插位置。
- 玩家使用 `CharacterBody3D`，可见 `CapsuleMesh` 与 `CapsuleShape3D` 尺寸一致；默认总高 1.8 米、半径 0.35 米、行走速度 3 米/秒。玩家受到正常重力，雾有效重力变化不得改变玩家行为。
- WASD 控制相机相对的水平移动，归一化输入避免斜向加速；忽略相机俯仰的垂直分量。由物理帧推进碰撞和移动，鼠标相对位移不重复乘帧间隔。
- 鼠标控制相机环绕胶囊上身目标点，偏航连续、俯仰限制在略低于水平至向下俯视的可用范围；不得翻转。默认相机后距约 4 米，目标点距地约 1.3 米。
- 进入游戏捕获鼠标；Esc 释放，单击非 UI 游戏视口恢复捕获。窗口失焦清除移动意图并释放鼠标，恢复焦点不突然转向；UI 点击不触发视角旋转或重新捕获。
- 相机只有一个位置/旋转控制者；碰撞收缩防止穿地，忽略玩家自身碰撞体。相机跟随应与物理移动时序协调，不能靠禁用角色碰撞消除抖动。
- 首选 Phantom Camera，执行时固定稳定发行版本与来源。原生相机回退只能用于已确认的兼容问题，操作契约保持不变，不能同时启用两套相机控制。
- 玩家可以直接走入雾中，但不作为高度场或雾障碍物，不发射或排开雾。
- 提供轻量说明/调试面板：操作提示、雾启停、模拟暂停/重置、诊断视图和关键参数。初始化组可调基础高度、噪波振幅/频率/层数/种子、噪波采样 X/Z 偏移，以及可为负的高度 offset；浮点数及整型数支持左键左右拖拽调节、Shift 精调、双击输入；数字参数变化立即重置雾场，拖动期间持续更新，不等松手或点击应用。初始化、动力与外观数字都遵循这一 UI 规则，开关不重置。另提供实时约化重力开关。暂停只停止模拟时间与噪声动画，玩家和相机继续工作。

## Boundaries, errors and compatibility

- 不包含跳跃、冲刺、角色动画、手柄和移动端。
- 插件兼容失败时明确记录版本、错误和回退路径，不静默修改引擎版本、不直接修补插件内部代码。
- 雾 GPU 初始化失败时保留可玩的场景并显示原因，不能导致玩家和相机失效；不得悄悄更换渲染后端掩盖问题。

## Acceptance scenarios

### P1 启动与尺度

运行主场景可见网格、胶囊和照明；地面与胶囊尺寸符合米制，角色静止时脚底贴地，边缘不会坠落。

### P2 相机相对移动

固定相机时分别向前、横向和斜向行走，水平速度一致；相机旋转 90 度后按 W，角色按新的水平前向运动。更改雾有效重力不改变角色下落与移动。

### P3 环绕与碰撞

绕角色转动一周并测试俯仰极限，相机不翻转、不穿地、不撞自身；物理角色移动与相机平滑跟随无明显周期性抖动。

### P4 输入与暂停

释放/捕获鼠标、窗口失焦/恢复、点击 UI 均没有意外移动或旋转；暂停模拟后角色仍可移动，雾状态与噪声时间保持不变；重置雾不传送玩家。

### P5 依赖与故障

记录实际启用的相机实现及插件版本；模拟初始化失败时仍可操作角色并读到错误。若使用原生相机回退，P1～P4 仍成立。

### P6 数字拖拽与实时重置

暂停模拟并释放鼠标，按住高度 offset 数值向左拖至低于 -0.6 米：松手前实际 GPU 雾厚已经裁切为零；仍按住向右拖回后立即出现雾，无需按重置按钮。拖动不捕获游戏相机、不解除暂停、不传送玩家；双击输入精确负值并确认后同样应用。所有数字仍遵守各自范围和步长。
