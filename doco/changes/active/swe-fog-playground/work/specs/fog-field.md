# 二维 SWE 雾场与体积渲染目标规范

## Scope and current contracts

这是本变更的目标。当前没有模拟或体积雾代码；参考水体项目只提供算法依据，不继承其海洋参数与行为。模拟依赖[高度场目标](terrain-bake.md)，观察与输入依赖[实验场目标](playground.md)。

## Requirements

- 在 XZ 网格保存 `h, qx, qz, m`：雾承载层厚度、两个方向的层动量、单位地面面积的雾含量。$u=q/h$，平均浓度 $c=m/h$，底部 `b`，顶部 `b+h`；空层采用安全除法且不残留动量或有效雾量。
- 支持统一雾顶 `h=max(H-b,0)` 与贴地厚度分布两种初始化；初始化支持确定性有符号 fBm 噪波：贴地厚度为 `max(0, base_height + amplitude*noise + height_offset)`；统一雾顶模式先扰动雾顶再减地面并裁切。高度 offset 可为负，裁切后局部可无雾；噪波振幅为零且 offset 为零时恢复无噪声初态。噪波采样 X/Z 偏移与高度 offset 是不同参数。初始 `m=c0*h`，可乘浓度遮罩，速度默认 0。统一雾顶在无风、无源时保持静止；恒定贴地厚度在斜坡上不被错误宣称为平衡。
- 所有压力、地形源项与波速使用一致的弱有效重力。玩家仍使用独立的正常重力。约化重力开关关闭时，压力、地形重力源项及 CFL 重力波速同时使用零有效重力，风、输送和消散仍工作，开关不自动重置状态。
- 风是水平目标速度，经有限响应时间趋近，驱动真实动量与输送；固定风不能使速度无限增长。首版用空间均匀微风，不加入逐帧白噪声力。
- 雾含量采用与层通量一致的守恒输送，消散主要减少 `m` 而非强制缩减 `h`。消散按模拟秒的半衰期积分；可选水平混合默认关闭。
- 状态不得为负或非有限；未开启源汇的封闭域维持雾量与层体积守恒，诊断中单独统计边界流出、消散与必要的极薄层清理，不把这些混为数值误差。
- 正常实验使用开放边界：流出允许离域，入流使用显式背景层厚、风速和浓度。默认入流浓度为 0，意味着有承载空气但不持续补充可见雾。无效格和障碍不通行；另提供封闭边界用于数值验证。
- 默认固定 30 Hz 模拟更新，可按 CFL 细分；实际推进时间用于风响应、消散与渲染噪声。长帧不得使用无界步长；达到子步预算时报告推进不足，不声称仍与墙钟严格同步。
- 运行时场和渲染纹理常驻主 RenderingDevice；不逐帧同步回读状态。初始化、重置、重建和释放遵守渲染线程与 GPU 读写顺序。
- 自定义 fog shader 用世界位置查询高度和二维场，按平滑垂直分布构造体密度；无效格、障碍和层外的连续密度为 0。渲染以有界 froxel 高度区间平均该密度，允许一个采样足迹内的边缘软化，不延伸模拟层或增加雾量。密度与层厚独立，不能只渲染顶面。
- 先实现无噪声密度映射；低频噪声为可关闭的渲染细节，不修改模拟质量。默认全局体积雾基底密度为 0，仅由局部 FogVolume 提供此雾场。默认浓白、脚踝高约 0.25 米，独立消光/亮度参数允许调浓而不增厚。
- 相机可以处于雾内；不透明地面和玩家正确遮挡。原生 froxel 和时间重投影的薄层/拖影限制需通过实际观察记录，不承诺未测量的画质或帧耗时。

## Boundaries, errors and compatibility

- 这是贴地、浅层、单值高度的视觉近似，不是完整三维烟雾或雾微物理。
- 初始目标是当前 Godot 4.7 Forward+ / Windows D3D12；资源格式或计算路径不支持时显式失败并保留基础场景。切换 Vulkan、降低精度或自建 Ray March 都不是静默回退。
- 初始化、运行、暂停、失败和释放有明确状态；初始化失败不发布半成品纹理，暂停不推进源项，重置清空动态历史但不改变玩家位置。
- 分辨率/区域变化要求匹配高度场并重建；直接配置更新不隐式重置。参数 UI 的所有数字变化按用户指定规则显式请求实时重置，约化重力、暂停等开关不重置。g_eff 等参数必须有限并在声明范围内。

## Acceptance scenarios

### F1 静止平衡与地形

封闭域、无风无衰减，统一雾顶覆盖平面及起伏夹具；推进 60 模拟秒后无持续增大的伪流，速度绝对值不超过 1e-3 米/秒，雾顶漂移不超过 1e-3 米。改变分辨率与 X/Z 格距后仍成立。

### F2 守恒、正性与障碍

封闭域、关闭消散与混合，使用有空间变化的正层厚/雾量和小速度推进 60 模拟秒；总层体积和总雾量相对漂移均不超过 1e-3，无负值、NaN、穿墙输送。测试中不得触发极薄层清理来解释质量损失。

### F3 微风与半衰期

均匀场、封闭域内部的无边界干扰短时验证或独立源项验证中，速度响应符合 $u=w+(u0-w)\exp(-t/tau)$。关闭输送/混合时，经过设定半衰期后总雾量为原值的 50%，相对误差不超过 1e-3；层厚不被同步减半。

### F4 时间与生命周期

同一初始状态、输入和累计模拟时间，30/60/144 FPS 驱动得到相近状态；无预算截断时总量与质心差异相对网格/总量尺度不超过 1e-3。暂停/恢复、重置、场景退出与重新进入不产生额外源项、悬空纹理或持续增长的 GPU 资源。

### F5 体积映射与遮挡

固定层厚改变雾量只改变浓淡，固定浓度改变层厚改变空间范围；调试视图与真实层顶一致。相机进入雾内、掠地观察及绕玩家转动时遮挡正确，层外无明显密度泄漏；记录 froxel 分辨率与重投影参数。暂停的薄雾不能因采样抖动而接地闪烁，绕行返回相同视角不留密度历史拖尾。无风无消散的非均匀初态，关重力保持静止，开重力需在实际主场景中推进并反映到画面；面板显示真实模拟时间、层厚范围、最大速度，不能仅显示“ready”。

### F6 性能与故障

GPU 接线原型验证主设备计算纹理可由 fog shader 消费，运行路径无逐帧同步回读。分别报告模拟与体积渲染的 GPU 计时；设备不支持计时时标记不可用，不把 CPU 提交耗时当 GPU 耗时。损坏资源、不支持格式或着色器错误能明确提示并禁用雾。

## Current-document impact

交付后同步当前雾状态、时间推进、边界、参数单位、GPU 生命周期和渲染契约；没有实测的数据不进入当前性能保证。自研渲染和更复杂物理需要后续独立决策。
