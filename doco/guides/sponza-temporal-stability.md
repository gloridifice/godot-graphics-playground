# Sponza View 3 暗部消闪：三组独立实测

后续：[A+C 与固定 0.995 的四组对照、实录和交互预览](sponza-temporal-combo995.md)。下文保留第一轮在 0.98 输入下的单项结果。

**在这个视角，最先值得改的是 `History Retention` 的可选上限，不是加屏幕降噪。** 三个原型中，自适应探针历史 A 是唯一同时达到预设画质、响应和耗时门槛的方案。为判断收益是否真的来自“自适应”，又给原算法加了一组固定 0.995 的对照。它比 A 更稳，在这次移灯测试中并没有更慢。正式工程尚未放宽 0.99 的上限，也没有启用任何原型。

## 画质和响应

Godot 4.7.2 Mono，Forward+ / Vulkan，RTX 3070。720p 固定 Arcade 相机、三盏原场景点灯、多次反弹、strength 3、LOD 7、stride 6；清空代理，追踪 426,964 个不透明三角形。A、B、C 都以 0.98 为输入、只改一个环节；固定 0.99 是作者当前保存的设置。质量测试各一次，GPU 计时另行重复。

| 配置 | 暗区平均亮度 | 平均相邻帧亮度差 ↓ | 相对固定 0.98 减少 | 横移边缘 MAE ↓ | 移灯后收敛帧数 ↓ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原算法 · 0.98 | 20.332 | 0.01825 | — | 0.426 | 21 |
| 原算法 · **0.99（现场）** | 20.418 | 0.00968 | 47.0% | 0.349 | 22 |
| A · 自适应探针历史 | 20.422 | 0.00663 | 63.6% | 0.375 | 22 |
| B · 每探针独立 R2 序号 | 20.371 | 0.01813 | 0.6% | 0.415 | 19 |
| C · 重投影与方差引导滤波 | 20.254 | **0.00217** | **88.1%** | 0.580 | **37** |
| 补充对照 · 固定 0.995 | 20.448 | **0.00553** | 69.7% | **0.349** | **22** |

- **静止：** 预热 512 帧，取 120 帧合成图；从 1280×720 每 4×4 取同一位置，不做缩放平均。亮度为显示空间 `0.2126 R + 0.7152 G + 0.0722 B`（0–255）。独立 stride 2 参考确定 34,648 个暗部采样点（原生 <16、参考合成 [4,40)）；关 GI 后静止帧间差为 0。该指标是对许多点、许多帧的均值，不表示任一像素只有这么小的跳变。暗区参考亮度 20.467；各组没有靠压黑画面过关。
- **横移：** 沿相机右轴移动 0.4 m，用时 32 帧；每 4 帧与相同位姿、stride 2、预热 480 帧后平均 24 帧的参考比较。在梯度 >8 且相邻参考位姿亮度变化 >4 的边缘计算 MAE。原生横移和原生固定位姿的采样亮度逐点相同，排除了相机错帧。此误差同时包含拖影、偏差和过滤造成的模糊；参考不是离线路径追踪真值。
- **移灯：** 只在内存把末端 GalleryLight 移动世界坐标 `(-2,-1.5,-2) m`，不移动另外两盏灯。7,710 个测点在前后均属直射暗部、原生亮度变化 <1、参考合成变化 ≥4。以各自移灯后长时间静置的均值作目标，连续 4 帧的 MAE 均 ≤ `max(1, 10% × 平均阶跃幅度)` 时，记录第一帧。阶跃约 16 个显示亮度单位。该插件在灯编辑时清探针历史；结果不能推出长历史对**不触发清空**的连续照明变化也没有延迟。

## 性能

单位 **GPU ms，中位数 / P95**。每个配置、每个分辨率取 3 轮 × 16 组完整 SRC 时间戳。每轮先预热至少 256 帧且至少 2.2 秒，采集时无图像读回。前五组轮换次序，0.995 是看完 A 的结果后追加的三轮，未参与轮换。视口样本独立采集，不与某个 SRC 标记强行配对。P95 尾部随轮次波动，不把百分之一毫秒的差异解释为加速。

| 配置 | 720p SRC | 1080p SRC | 1080p 整个视口 | 额外常驻图像（720p / 1080p） |
| --- | ---: | ---: | ---: | ---: |
| 固定 0.98 | 0.628 / 1.117 | 1.232 / 2.542 | 2.807 / 4.164 | 0 |
| 固定 0.99 | 0.622 / 1.042 | 1.210 / 1.882 | 2.756 / 3.950 | 0 |
| A 自适应 | 0.633 / 1.162 | 1.225 / 1.889 | 2.768 / 4.148 | 0，复用方向桶的 2 个浮点数 |
| B 探针 R2 | 0.628 / 1.189 | 1.214 / 1.520 | 2.750 / 3.693 | 0，复用槽位计数 |
| C 屏幕滤波 | 0.923 / 0.959 | **1.864 / 2.741** | **3.449 / 4.887** | **35.16 / 79.10 MiB** |
| 固定 0.995 | 0.633 / 0.865 | 1.249 / 1.675 | 2.806 / 3.544 | 0，与原算法同一着色器 |

C 的开销集中在 Apply：1080p 从固定 0.98 的 0.452 ms 升到 1.108 ms。它使用 5 张 RGBA16F 图像（40 B/内部像素，名义容量，不是驱动分配量实测）。A 的 Merge 从 0.050 到 0.059 ms；B 的 Trace 从 0.300 到 0.299 ms，没有可辨别的求交提速。[各阶段、两种分辨率的中位数/P95 和样本数](../../tools/src_temporal_study/results/gpu.csv)。

## 取舍

- **A 可以保留，但现在不必接入。** 相比现场 0.99，A 的帧差再降 31.4%，移灯都是 22 帧，1080p SRC 增加 0.015 ms。A 的稳定方向最高保留率恰为 0.995；固定相同上限后，帧差反而比现场降低 **42.9%**，横移误差和移灯响应不退步。这说明在本场景不能把 A 的全部收益归给自适应判断。建议下一步只开放 0.995 的可选范围、保留旧默认，再验证冷启动、编辑器 64 帧重绘窗口和连续移动；本轮只测了所述亮度阶跃和短横移。
- **B 不作为消闪修复。** 与同为 0.98 的基线只差 0.6%，移灯略早；静止结果远落后于现成的 0.99。这组验证的是原子领取序号的世界探针 R2，不等于验证了所有低差异序列，也没测试 STBN 纹理。
- **C 适合静态观看，不适合作交互默认。** 它把快速闪烁压得最多，但低帧差并不意味着光照已跟上：移灯比现场慢 15 帧，横移边缘误差由 0.349 升到 0.580，1080p SRC 多 0.654 ms。预设门槛中，C 同时未过移灯响应与 GPU 预算。此原型对静态几何重投影，只过滤未乘底色的间接光，不是完整 SVGF 或通用运动物体降噪器。

三个原型在 Vulkan 硬件模式下均通过 addon 的 `render_test.gd`；A 另通过 `interval_bins_test.gd`。未把这些结果外推到 D3D12、其它 GPU、编辑器多视口或不同光照场景。

## 复跑

需要 Git、Python 3 + NumPy、Godot 4.7.2 和支持 Vulkan RT 管线的真实设备。项目根目录执行，使用一个**新的仓库外目录**。命令创建最小 Sponza 副本，不启动或修改正在使用的项目编辑器。

```powershell
$tool = 'tools/src_temporal_study'
$lab = 'G:/tmp/sponza-temporal-replay'
$exe = 'G:/Tools/Godot_mono_v4.7.2/godot_console.exe'
python "$tool/run.py" all --out $lab --godot $exe
# 可选：再测只放宽脚本限幅、着色器不变的 0.995 对照
foreach ($phase in 'prepare','quality','timing') {
    python "$tool/run.py" $phase --out $lab --godot $exe --cases fixed995
}
python "$tool/analyze.py" $lab "$lab/summary" --with-ablation
```

不测补充对照时，分析命令去掉 `--with-ablation`。各次 `run.log`、RGB8 帧、导入工程和时间戳留在 `$lab`；仓库保留[输入指纹](../../tools/src_temporal_study/results/inputs.json)、[质量数据](../../tools/src_temporal_study/results/quality.csv)和[门槛判定](../../tools/src_temporal_study/results/gates.csv)。
