# 程序化攀爬 / 悬挂

针对当前 Mixamo 守卫骨架，使用原生 `CharacterBody3D`、`SkeletonModifier3D` 和左右独立 `TwoBoneIK3D`。不需要外部攀爬动画或编辑器插件。

## 操作

- **离开地面后自动抓握**：肩附近的正上方、前斜上方射线找到同一有效区域，且双臂可达、进入路径和身体空间有效，即进入 `Climb`。不要求鼠标捕获、按抓握键或持续按住跳跃；站在地面不抓握。
- **WASD**：顶面沿相机方向在表面移动；墙面 W／S 上下、A／D 横移。交替换手，至少保留一只支撑手。没有下一抓点或身体空间时停住。
- **不输入、释放鼠标或失焦**：保持悬挂，停止规划新一步；已经开始的一次换手会完成。
- **吸附时按 ESC**：立即解除抓握并释放鼠标，恢复普通空中物理。该角色在本次腾空期间拒绝所有区域的再次吸附，松开按键、换区域或等待都不会解除。
- **真实落地**：清除 ESC 禁用标记，下一次离地可以再次吸附。轻落地同样有效，不依赖有速度阈值的 `landed` 信号。
- **未吸附时按 ESC**：只释放鼠标，不禁止后续抓握。支撑被删除、禁用或约束失效导致的非主动掉落也不禁止重抓。

空格仍只负责接地跳跃；没有空中弹离。Ctrl 不作为松手键，蹲姿尚未恢复站姿时不抓握。

## 放置区域

在环境表面添加 `Area3D`，挂载 `climbable_area.gd`，也可通过全局类创建 `ClimbableArea3D`，再添加 `CollisionShape3D`。默认使用层 3（位值 `4`），不产生实体碰撞、不依赖进入／离开区域信号。

**区域形状的边界就是掌心抓握表面。** 将它贴合可见模型，并为模型保留独立的环境碰撞体（层 1）。不要用一个宽松的大触发盒包住墙，否则手会抓在盒边而不是墙上。区域只表达抓握许可，不生成可见几何或实体碰撞。

- `enabled`：禁止新抓握，并使现有抓握在下一物理 tick 失效。
- `speed_scale`：换手速率，默认 `1`。
- `max_up_normal`：允许抓握面的世界向上法线分量上限，默认 `0.35`，拒绝盒子的顶面。
- 移动表面：将区域作为移动实体的子节点；抓点保存为区域局部变换，可跟随平移和 yaw。

现成示例为 `../demo/climbing_course.tscn`，青色墙和顶板的可见几何、实体碰撞和抓握形状一致。主场景在 `(10, 0, 7)` 附近；独立 demo 放在空闲的 `(-10, 0, 12)` 附近，Tab 最后两个检查点分别是顶面和墙面，空格起跳即可。

## 求值与标定

角色每个固定物理 tick：

```text
真实接地 / ESC 标记 → 空中区域查询或换手规划
→ 支撑局部抓点 → 双臂约束反推身体目标 + 阻尼摇摆
→ CharacterBody3D.move_and_slide() → 可达性复核
→ AnimationTree.advance()（Climb 静态完整基础姿态）
→ MotionPoseSample（攀爬不做地面检索 / decay）
→ FootPlacement / 双腿 IK（攀爬离地，清锁并旁路）
→ ClimbPose（骨盆摇摆、抬肩、手腕目标）
→ LeftArmIK / RightArmIK → HandRotations
```

抓握期掌心锚点不随检测射线重新采集。掌心目标扣除骨骼局部偏移，得到手腕 IK 目标；末端旋转修改器再对齐掌心朝向。身体反推先选择悬垂姿态，再投影到双臂可达范围，不将“固定手的位置”误当成能唯一求出肩的位置。身体和进入路径始终受真实胶囊碰撞约束，不拉长骨骼，不用视觉移动掩盖碰撞失败。

`guard.tres` / `MotionClimbSettings` 是共享配置，不保存任何运行时锁点。默认查询长 `0.95 m`、初次身体调整范围 `0.5 m`、附着过渡 `0.18 s`、换手步距 `0.28 m`、周期 `0.32 s`；臂长来自骨架，悬垂伸展比例 `0.9`、墙面肩距 `0.42 m`、抬肩 `35°`。守卫的手指朝局部 ±X，掌心朝 −Y，掌心偏移为 `(±0.09, -0.025, 0)` 米。更换骨架或标定后应重新进入场景。

摇摆由相对支撑运动的实际加速度驱动阻尼响应，默认限幅 `6°`；在双臂 IK 前施加，不在 IK 后整体旋转模型。角色胶囊保持竖直。首帧抓取有短暂混合，稳定支撑期的手才是完整锁定。

运行时可通过 `character.climbing.is_attached()`、`is_blocked_until_grounded()` 和只读 `get_debug_state()` 查询状态；demo 面板显示阶段与 ESC 禁用提示。显式传送／复位调用 `character.climbing.reset()`，它也清除 ESC 标记；单 tick 超过 1 m 的位置突变按复位处理。

## 边界与验证

仅支持 Y 朝上、单位缩放和当前守卫标定。首版支持同一区域、同一近似平面上的移动及支撑平移／yaw；不跨区域换手、不绕复杂转角、不跨大间隙、不翻上平台、不提供踩墙脚部 IK、手指握合或完整全身动力学。普通碰撞体没有区域时不能抓握。支撑速度过快、手臂超限或身体碰撞导致约束无法保持时会掉落，非主动掉落仍可重新抓握。

自动化测试（无需焦点或鼠标捕获；需要看画面时去掉 `--headless`，窗口仍不可聚焦）：

```powershell
godot --headless --path . --script res://addons/motion/tests/climbing_test.gd
# 可选物理频率，分别验证稳定性；不是逐帧轨迹相等测试。
godot --headless --path . --script res://addons/motion/tests/climbing_test.gd -- --rate=30
godot --headless --path . --script res://addons/motion/tests/climbing_test.gd -- --rate=120
```

测试通过 `MotionCharacter.set_external_input()` 和 `release_climb()` 驱动正常控制器，使用真实区域射线、胶囊碰撞、原生状态机和最后一个修改器的最终骨骼，对照独立盒体表面检查掌心位置／朝向、臂长、顶面与墙面移动、支撑局部锁定、禁用／恢复、ESC 和无落地信号的轻接地重置，以及实体障碍拒绝。当前检查环境为 Godot 4.7.2 / Forward+ / D3D12。
